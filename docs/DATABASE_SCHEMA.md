- Manufacturer
- MotorcycleModel
- MotorcycleVariant
- ProductionGeneration
- EngineSpecification
- TransmissionSpecification
- GearSpecification
- TireSpecification
- TechnicalSource
- ModificationRule
- Tutorial

All technical values need source metadata, verification state, applicable model year/generation, and revision history. Do not use a single generic specification for all variants of a model.
